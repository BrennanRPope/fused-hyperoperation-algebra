1. The Frey curve's invariants, symbolically
==============================================================================
c4   = 16*(A**2 + A*B + B**2)
c6   = 32*(A - B)*(A + 2*B)*(2*A + B)
Disc = 16*A**2*B**2*(A + B)**2
c4^3 - c6^2 - 1728*Disc = 0
minimal model (u = 2): c4 = A**2 + A*B + B**2 | c6 = (A - B)*(A + 2*B)*(2*A + B)/2 | Disc = A**2*B**2*(A + B)**2/256
identity 4(A^2+AB+B^2)^3 - ((B-A)(2A+B)(A+2B))^2 - 27(ABC)^2 = 0
j = c4^3/Disc = 256*(A**2 + A*B + B**2)**3/(A**2*B**2*(A + B)**2)

2. The exponent of 2 in the minimal discriminant never lands on a multiple of p
==============================================================================

pairs (p, v_2(b)) with p | 2p*v - 8, p in [5,200), v in [1,40): none
Reason: 2p*v - 8 = -8 mod p, and an odd prime never divides 8.

5. Local (mod q) obstructions only push divisibility, never contradict
==============================================================================
p = 5: primes q < 400 where x^p + y^p = z^p mod q forces q | xyz: [11, 41, 71, 101]
p = 7: primes q < 400 where x^p + y^p = z^p mod q forces q | xyz: [29, 71, 113]
Each one only says q divides abc. Solutions with abc != 0 exist in every q-adic field,
e.g. 1 + (q t)^p = c^p has a q-adic root c for q != p (Hensel), so no local test can
ever rule a counterexample out.

==============================================================================

  2 + 6436341 = 6436343: quality 1.6299
  121 + 48234375 = 48234496: quality 1.6260
  24833 + 5020969537415167 = 5020969537440000: quality 1.6235
  283 + 8251953125 = 8251953408: quality 1.5808

  a counterexample with p = 5 would need quality > 1.6667
  a counterexample with p = 7 would need quality > 2.3333

10. The reducible escape: a real curve where the squeeze closes except for Mazur's arrow
==============================================================================
Curve from -125 + 128 = 3: conductor 30 torsion [2, 2]
Disc_min = {2: 6, 3: 2, 5: 6} - for p = 3 the exponents at 2 and 5 are multiples of 3,
isogeny degrees in its class (PARI ellisomat): [1, 2, 3, 4, 6, 12]
so the mod-3 Serre level drops to 1 (and the weight rises because 3 does not divide v_3 = 2,
so no level-1 form exists either), yet there is no contradiction: the curve has a rational
3-isogeny, its mod-3 representation is reducible, and Ribet's arrow needs it irreducible.
That is exactly the hole Mazur's theorem plugs for the Frey curve when p >= 5.
