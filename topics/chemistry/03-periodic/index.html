Lead check: not a lead

The square shells are SO(4), known since 1935, and the doubled-square periods are Janet's 1928 table. The exception pattern (always a neighbour on the diagonal, never more than two electrons) is a clean regularity I found no single statement of, but it is what the standard near-degeneracy explanation predicts, so it opens nothing new.

Each shell is a square, and its subshells are the square's gnomons

Hydrogen's shell n holds subshells l = 0 to n − 1 with 2l + 1 orbitals each: 1, 3, 5, 7. Those are the L-shaped gnomons that build an n × n square, corner plus two edges each time, so the shell holds n² orbitals:

n² = 1 + (n − 1) ∘₁ (n − 1)

The square is not a coincidence. Hydrogen's hidden symmetry is SO(4), which splits into two independent spins of the same size j, with 2j = n − 1. Each spin has n states, the two multiply to n · n, and decomposing j ⊗ j by the Clebsch–Gordan rule gives exactly l = 0 to n − 1. So each shell is the lift of a circle operation ∘₁ (called mult-add before 1.0) of two equal spins, with a geometric underpinning we can be sure of (Fock, 1935).

The periods are the Madelung diagonals, and each holds a doubled square

Atoms fill subshells in order of n + l, then n (the Madelung rule). Each diagonal n + l = s holds 2 · ⌈s/2⌉² electrons: 2, 2, 8, 8, 18, 18, 32, 32. Those are the periods of Janet's left-step table exactly. The usual table merges the first two diagonals, giving periods 2, 8, 8, 18, 18, 32, 32 and noble gases at 2, 10, 18, 36, 54, 86, 118. Lean computes all three lists and proves that period 2k + 1 has the length of diagonal 2k + 2.

Why the periods come in doubled squares is the same gnomon count run along a diagonal instead of a row: a diagonal picks up one subshell of each odd size up to its length, and odd numbers sum to squares.

All 20 exceptions move one or two electrons to a neighbouring diagonal

Twenty elements have ground states that break the Madelung order (Wikipedia's Aufbau table: Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag, La, Ce, Gd, Pt, Au, Ac, Th, Pa, U, Np, Cm, Lr). I compared each with the rule. Every one moves only one or two electrons, and always between subshells at most one diagonal apart. Ten of them never leave their diagonal at all: La, Ce, Gd, Ac, Th, Pa, U, Np and Cm swap between d and f on one diagonal, and lawrencium swaps 6d for 7p on diagonal 8. The other ten move an electron from an s subshell up one diagonal into d. No exception touches a p subshell except lawrencium's.

So the diagonals are sturdy and the exceptions are near-ties between neighbours, which matches the usual explanation (subshells on adjacent diagonals have nearly equal energies in heavy atoms). The red badges on the picture count how many exceptions touch each subshell.

The dial gives q-deformed shells, but I found no chemistry that uses them

The q-integer [n]q = 1 + q + … + qn−1 is exactly n copies of 1 under the circle operation with k = q − 1. A q-deformed shell would hold [n]q² orbitals, and Negadi and Kibler built a q-deformed periodic table this way in the 1990s. Nothing in real atomic data asks for q ≠ 1: the shells are exact squares. This is a placement on the dial, not a finding.
