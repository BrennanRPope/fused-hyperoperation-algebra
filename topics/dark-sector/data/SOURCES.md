# Data sources (downloaded 2026-11-25)
- SPARC (Lelli, McGaugh & Schombert 2016, AJ 152, 157). Official host astroweb.cwru.edu is not reachable from this environment, so the
  files were taken from public GitHub mirrors: Table 1 from JuliaAstroSim/AstroIC.jl (src/data/SPARC_LTGs/SPARC_Lelli2016c.mrt.txt),
  the 175 *_rotmod.dat files from MoPl90/cosmological_tests (data/Rotmod_LTG). Spot-checked against the paper (NGC2403 D=3.16 Mpc, etc.).
- Pantheon+ (Scolnic et al. 2022, Brout et al. 2022): PantheonPlusSH0ES/DataRelease, Pantheon+SH0ES.dat and STAT+SYS covariance.
- DESI DR2 BAO (DESI Collaboration 2025): CobayaSampler/bao_data, desi_bao_dr2 GCcomb mean and covariance.
