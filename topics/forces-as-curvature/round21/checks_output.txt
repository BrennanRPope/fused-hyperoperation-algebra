== W. Why Lorentzian?
PASS W1 (exact) along any one direction the law is a Moebius map with matrix [[1, a], [-c a, 1]], c = q.eta(v, v). If c > 0 it is a rotation: repeated kicks go round and come back exactly (space closing, rounds 12-13). If c < 0 it is a boost: repeated kicks march one way for ever, in equal rapidity steps, never reaching the edge 1/sqrt(-c) (an ordered direction with a horizon). If c = 0 it is plain addition. Which kind is fixed by the sign of c alone  | c = +1: 24 kicks pass the far point half way and return to the start (1e-16); c = -1: 40 kicks strictly increasing, largest 0.999988 < 1, rapidity steps equal to 3e-12; c = 0: equal steps to 4e-16; trace^2/det = 3.448 (< 4, rotation), 4 (= 4, plain), 4.762 (> 4, boost)
PASS W2 (exact) light needs a minus sign. Along any direction v the law is the 1D law with dial c = q.eta(v, v), so it ignores the dial (plain addition, a signal whose speed no q changes) exactly when eta(v, v) = 0. With an all-plus dot product eta(v, v) = |v|^2 > 0 for every v != 0, so no direction escapes the dial. With one minus sign there is a whole cone of them  | 5000 random directions, both dot products: the law along v vs the 1D law with c = q.eta(v, v) 8e-13 (relative, away from the far point); all-plus dot: smallest c 0.016 > 0; one minus sign: along the light cone, law vs plain addition 4e-16
PASS W3 (exact for the explicit loops; random search for the rest) time can loop unless exactly one direction is ordered. With one minus sign, any closed curve must stop moving in time somewhere, so it can't stay time-like all the way round: time is ordered. With two or more, a circle in the time plane is time-like all the way round, a closed time-like loop  | 0 minus signs: random closed loops time-like throughout: none; 1 minus sign: random closed loops time-like throughout: none; 2 minus signs: circle in the time plane, largest eta(v, v) -1.00 < 0; 3 minus signs: circle in the time plane, largest eta(v, v) -1.00 < 0; 4 minus signs: circle in the time plane, largest eta(v, v) -1.00 < 0
PASS W4 (exact) round 15 read time as the fused shift, a forward run of the law plus its inverse run. Along an ordered direction (c < 0) the two runs share only their start, the bounce. Along a closed direction (c > 0) they meet again every half turn, so time built that way would have no single bounce. So round 15's reading itself needs time to be the ordered kind  | 400 steps each way: ordered direction, meetings after the start 0; closed direction (40 steps per half turn) 20
PASS W5 (exact) only one minus sign meets all four needs: a space that closes (rounds 12-13), a direction that is ordered (time), light that ignores the dial (W2), and no time loops (W3). Flipping the dial's sign and the dot product's together leaves the law unchanged, so q < 0 with three minus signs is the same answer. So the law's own behaviour, plus these four needs, picks one time and three space directions  | minus signs 0-4: 0: closes y, ordered n, light n, no loops y; 1: closes y, ordered y, light y, no loops y; 2: closes y, ordered y, light y, no loops n; 3: closes y, ordered y, light y, no loops n; 4: closes n, ordered y, light n, no loops n; law unchanged when both signs flip 0e+00
