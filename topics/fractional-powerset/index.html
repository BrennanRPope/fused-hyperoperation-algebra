A dial between a set and its power set

With the axiom of choice, a smooth dial of power sets is impossible, and even a single half step is optional: some worlds have one, others don't. Leave choice off and the obstacle disappears. Nobody has built the dial there or ruled it out, so it is a sharp open question.

You asked for a family Pt, one operation for every t between 0 and 1, with P0 doing nothing, P1 taking all subsets, and Ps then Pt landing where Ps+t does, all counted by size. Half is the first test.

Each operation must be monotone: a bigger set never gets a smaller result. Every natural set-building operation is.

Left: with choice, sizes are rungs and the halvings P1/2, P1/4, P1/8… must each land on a lower rung, so they run out. Right: without choice, sizes can sit densely, and the dial is neither built nor ruled out.

Six findings

  1. The finite wall. No monotone rule on whole numbers has f(f(n)) = 2ⁿ. It already fails at n = 0 and n = 1. Starting from n = 2, a strictly increasing one exists: 3, 4, 8, 9, 10, 11, 16, 32, 64, 128, 129, …, but it is patched together by hand.
  2. One half step on infinite sizes is optional. A monotone half power set must land strictly between κ and 2κ. If the continuum hypothesis holds at every size, there is no room. In worlds where 2κ = κ⁺⁺ for every infinite κ (consistent from a large cardinal, Merimovich 2007), the plain next-size-up operation is a half power set.
  3. The full dial is impossible with choice. Even just halving over and over: the halvings P1/2(κ), P1/4(κ), P1/8(κ)… must strictly decrease, and well-ordered sizes cannot decrease forever. Proved in four lines, and in Lean on a well-ordered scale.
  4. Without choice the obstacle is gone. Sizes can then fall forever, even with a lot of choice left (Karagila 2014: decreasing chains are consistent with DCκ for any κ). I found no result that builds the dial or rules it out.
  5. Natural constructions are blocked. The half step of "make a set of sets" has fractional and negative counts: ex − 1 has the half iterate x + x²/4 + x³/48 + 0·x⁴ + x⁵/3840 − 7x⁶/92160 + …, so the 2-element count would be ½. Any choiceless dial would have to come from symmetry, not from a formula.
  6. Choice is a position on the rung ladder. Successor flat on infinite sizes, addition flat, multiplication flat: each is a stronger grade of choice, and the last is full choice. Exponentiation is never flat, and that is exactly where the power set lives.

With choice: one step maybe, a dial never

Why a half step has to land strictly in between

Say F is monotone and F(F(κ)) = 2κ. If F(κ) ≤ κ, then F(F(κ)) ≤ F(κ) ≤ κ, but 2κ is bigger than κ. If F(κ) ≥ 2κ, then F(F(κ)) ≥ F(2κ) > 2κ. So κ < F(κ) < 2κ, and with choice that means 2κ is at least two rungs above κ, at every κ where F works.

κ < F(κ) < 2κ   so   2κ ≥ κ⁺⁺

When the half step exists

Easton (1970) showed the power function can be almost anything on regular cardinals; the singular ones resist, which is why a global answer needs large cardinals. Merimovich built worlds where 2λ = λ+n for every λ, for any fixed n. In the n = 2 world, "next size up" composed with itself is "two sizes up", which is the power set. A whole-number check shows the pattern: a monotone square root of "jump d rungs" exists only when d is even. So the n = 3 world has no half power set at all.

Why the dial cannot exist

Write Pk for P1/2k, so each Pk+1 done twice is Pk. If some Pk+1 ever failed to grow a size, then Pk = Pk+1∘Pk+1 would fail too, and so on up to P itself, contradicting Cantor. So every level grows. Then

Pk(κ) = Pk+1(Pk+1(κ)) > Pk+1(κ)

which gives an infinite strictly decreasing sequence of sizes, all above κ. With choice, sizes are well-ordered, so that cannot happen. The argument needs only the dyadic fractions, so every version of the dial that halves is dead, not just the continuous one.

Without choice: where a dial could live

Drop choice and sizes stop being well-ordered. Jech and Sochor showed any ordering can appear among the sizes of some model, and Karagila showed this survives a lot of dependent choice. So the one obstruction above is gone. What remains are a few hard facts that hold with no choice at all:

  • The finite wall at sizes 0 and 1, so a rung axiom must start above them.
  • For an infinite set, the finite subsets are always fewer than all subsets (Halbeisen–Shelah 1994).
  • Two power sets in a row are always Dedekind-infinite (Kuratowski), and their size absorbs doubling (Läuchli).

None of these rules out a half step. They only fix the walls the dial would have to fit between.

The best evidence a dial could fit

With choice, infinite arithmetic is flat: a + b, a·b and a ∘₁ b are all just the larger size, the tropical, fully zoomed-out view. Without choice, infinite sizes can remember finite growth. In the ordered Mostowski model, Halbeisen and Shelah found the same order as for finite counts: m < fin(m) < 2m < injective sequences. Half-exponential growth is a finite growth rate, so the question becomes whether a choiceless world can remember it too.

In the ordered Mostowski model every subset of the atoms has a least finite support, and the subsets with a support of n atoms number exactly 2·3ⁿ (checked by brute force and by inclusion–exclusion). So the power set reads like the series Σ 2·3ⁿ xⁿ, against Σ xⁿ for finite subsets and Σ n! xⁿ for injective sequences.

What decides the in-between sizes

In these models the power set takes the number of orbits a set has around n atoms, o(n), and turns it into about 2o(n) elements per support. For the atoms o(n) = 2n + 1; for pairs of atoms o(n) ≈ 2n², and the power set count grows like 22n². Sets built from boundedly many atoms have polynomial orbit counts, so, heuristically, a half step needs a symmetry group whose orbit counts grow faster than every polynomial but slower than exponential. Such groups exist (S∞ wr S∞ grows like the partition numbers, about ec√n), and there are theorems forbidding some bands (Macpherson's gap for primitive groups, sharpened by Simon). That is the concrete place to look.

The rung axiom, stated

Rung axiom RA(D). For every t in D there is an operation Pt on sets with at least two elements such that: each Pt is monotone in size; P0(X) has the size of X; P1(X) has the size of the power set of X; and Ps(Pt(X)) has the size of Ps+t(X) whenever s + t ≤ 1.

Choice as a position, not a switch

Your idea was that choice falls out of where you sit on the flow. There is a clean version of that, and it uses the rungs themselves. Ask which hyperoperation goes flat on infinite sizes, meaning m ∘ m = m for every infinite m:

  • Successor flat (m + 1 = m): every infinite set is Dedekind-infinite. A weak grade of choice.
  • Addition flat (m + m = m): strictly stronger, still strictly weaker than full choice.
  • Multiplication flat (m·m = m): exactly the axiom of choice (Tarski 1924). The circle operation ∘₁ (called mult-add before 1.0) flat is the same thing, since m ∘₁ m sits between m·m and itself.
  • Exponent flat: never, by Cantor. The power set is the first rung that cannot go flat in any world.

Each grade implies the one below it, proved from rules that hold without choice, and the implications are strict. So choice is the height to which infinite arithmetic goes flat. The dial question sits right at the top: full flatness of multiplication is what kills the dial.

But the landscape is not a line

The grades of choice form a partial order, not a ladder. The Boolean prime ideal theorem and dependent choice are incomparable: Cohen's basic model has the first and an infinite Dedekind-finite set of reals, so not even the successor rung is flat there; Solovay's model has dependent choice and no free ultrafilter on ℕ. The ordered Mostowski model has every set linearly orderable and the prime ideal theorem, yet no rung is flat. The rung ladder is one honest line through a landscape with at least two more independent directions.

Verdicts

The fractional power set: a lead worth following. With choice it is settled by this page. Without choice it is a clean, well-posed open question, and the one known obstruction does not apply. The catch is honest: every natural formula for a half step gives fractional or negative counts, so the geometric underpinning you want would have to come from a symmetry group with in-between orbit growth, not from a formula. The next step is concrete: take a group whose orbit counts grow like ec√n, build its permutation model, and see whether some set there behaves like a half power set of the atoms.

Choice as a position: a real picture, a modest lead. The rung ladder does index grades of choice, strictly, and it puts the power set exactly where flatness becomes impossible, which fits the fused picture well. But it has only three steps, it is built from classical theorems, and the full landscape has other independent directions. k only reproduces the add-versus-multiply split, and the twist has nothing to act on. The one sub-question worth checking is whether a rung between addition and multiplication, such as ℵ₀·m = m, is its own grade of choice; Howard and Rubin's tables may already answer it.
